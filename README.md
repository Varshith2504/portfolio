# Ellendula Varshith — Professional Portfolio

A modern, high-performance developer portfolio built with React 18, TypeScript, Vite, Framer Motion, and Lucide Icons. Features interactive micro-animations, clean dual-tone aesthetic, project showcases with modal views, categorized technical skills, and resume downloads.

---

## 🚀 Live Demo & Features

- **⚡ Modern Tech Stack**: React 18, TypeScript, Vite, Framer Motion, Lucide Icons.
- **🎨 Curated Dual-Tone Theme**: Royal Tech Blue (`#2563eb`) & Slate Navy (`#0f172a`) on clean, modern surfaces.
- **✨ Fluid Animations**: Smooth entry reveals, dynamic role typing effect, interactive project modals, and spring-physics custom cursor.
- **📁 Projects Showcase**:
  - **Collab Hub**: Student Team Collaboration Portal with React, Spring Boot, MySQL, REST APIs.
  - **Expense Vision**: OCR-Based Receipt Processing & Fraud Detection with Python AI/ML.
- **🛠️ Categorized Skills**: Programming languages, databases, tools, and computer science core concepts.
- **🎓 Academic & Certifications**: Timeline for Anurag University and verified credentials from Google Cloud, Infosys, and Wipro.
- **📄 Resume Download**: Direct 1-click PDF resume download integrated in navbar and hero section.
- **📬 Direct Contact Hub**: 1-click email & phone copying with direct profile links to GitHub and LinkedIn.

## 📦 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Varshith2504/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173/`.

4. **Build for production**:
   ```bash
   npm run build
   ```
